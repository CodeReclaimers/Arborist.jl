# Infrastructure — API Reference

Autogenerated reference for evaluators, novelty search / MAP-Elites archives,
structured run logs, checkpoint / resume, constant optimization, the AST
sanitizer, code-generation primitives, the protected arithmetic operators
used in symbolic regression, and shared run-utility helpers
(`train_test_split`, `summarize`, `run_multi_seed`).
