# 2026-04-10 — Prompt enrichment ablation results

## Summary

The ablation experiment launched on 2026-04-09 completed overnight
(total wall 39551s ≈ 11 hr). All 4 variants × 5 seeds = 20 runs
finished successfully. `ElitesSection(3)` — showing the LLM the
top-3 programs with their fitnesses — is the clear winner.

## Key findings

1. **Elites alone > everything else.** The FunSearch pattern (showing
   scored programs) is the dominant signal. `elites_3` improved mean
   test by 0.011 and jumped from 1/5 to 4/5 seeds beating Best Fit.
   Best single result: seed 1337 at 1.0513 (5.2% better than BF).

2. **Adding fitness context and generation phase to elites hurts.**
   `full` (fitness + elites + generation) scored mean 1.0708 vs
   elites-only 1.0623. The extra prompt text likely distracts the
   model or pushes it toward conservative mutations. Simpler framing
   ("here are good programs, improve this one") outperforms richer
   framing ("here's your rank, phase, good programs, improve this").

3. **Fitness context alone is marginal.** `fitness_only` moved the
   mean by -0.0036 but inconsistently — helps on seeds 123 and 1337,
   neutral-to-slightly-worse on others. Knowing how bad you are
   without seeing what good looks like isn't actionable for the LLM.

4. **Wall time scales with prompt size.** baseline 1568s → elites_3
   2049s (+31%) → full 2374s (+51%). The extra tokens cost inference
   time; only elites_3 provides quality improvement that compensates.

5. **LLM parse success improves with enrichment.** baseline had 105
   deserialize-returned-nothing fallbacks out of ~6050 calls (1.7%),
   while enriched variants had 0–2. The enrichment preamble and
   "--- Program to mutate ---" separator give the LLM better framing
   for the expected input/output format. Zero sanitizer rejections
   across all variants.

6. **All variants: ~100% LLM pipeline success.** The `_build_sanitizer`
   fix from `d9932b9` is confirmed working. No sanitizer rejections
   in any of the 20 runs.

The `elites_3` result (1.0623 mean, 1.0513 best) is the best
multi-seed LLM result to date. It matches the 800-generation
classical GP extended run (1.0623 test from G3A) but achieves it
in 100 generations — an 8x generation-count efficiency gain.

## Deserialize failure analysis

baseline had 105/6050 (1.7%) deserialize-returned-nothing fallbacks.
Enriched variants had 0–2. The enrichment preamble provides structural
framing ("--- Program to mutate ---") that helps the LLM distinguish
the code to modify from the surrounding context, producing more
reliably parseable output. This is a minor secondary benefit of the
enrichment mechanism beyond the primary information content.
