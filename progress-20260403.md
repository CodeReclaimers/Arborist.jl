# Progress Log — 2026-04-03

## Feynman Symbolic Regression Benchmark

Added `examples/feynman_regression.jl` — a standalone benchmark that runs Arborist against the AI Feynman symbolic regression dataset (Udrescu & Tegmark, 2019/2020). Data is downloaded from PMLB (Penn Machine Learning Benchmarks) on first run and cached locally.

### Six difficulty levels

| Level | Equations | Description |
|-------|-----------|-------------|
| smoke | 5 | Trivial 2-variable products/ratios |
| standard | 12 | Moderate: Lorentz factor, trig, interference, magnetization |
| bonus | 8 | Hard bonus set: Compton, Kepler, Klein-Nishina, rel. Doppler |
| full_standard | 99 | All Feynman Lectures equations |
| full_bonus | 20 | All AI Feynman 2.0 bonus equations |
| everything | 119 | All of the above |

### Genome support

- **TreeGenome** (default): 10x faster evaluation via DynamicExpressions.jl. Primary benchmark path.
- **ExprGenome** (`--genome=expr`): Supported but impractical for this benchmark due to `@eval` compilation overhead and progressive method table growth.

### TreeGenome results (300 generations, pop=200, 3 seeds)

**Smoke tier (5/5 solved):**
All equations converged on at least one seed. Simple products/ratios (F=mu*Nn, V=q/C, k=omega/c) solved 3/3. Equations requiring constant discovery (½kx², 3/2·pV) solved 1/3. Total wall time: 19s.

**Standard tier (6/12 solved):**
- Perfect recovery (3/3 seeds): m·g·z, r·F·sin(θ), n·kB·T/V
- Partial convergence (1-2/3 seeds): E=mc²/√(1-v²/c²), ε·E²/2, -μ·B·cos(θ)
- Stuck: Lorentz factor m₀/√(1-v²/c²), arcsin(n·sin(θ₂)) (arcsin not in operator set), q/(4πε·r) (collapsed to constant — 4π constant discovery failure), tanh equation (tanh not in operator set)
- Total wall time: 51s

**Bonus tier (0/8 solved):**
- Best: Kepler's third law at R²=0.984, orbital mechanics at R²=0.946
- Klein-Nishina (7 variables): severe overfitting, train R²=0.97 but test R²=-0.24
- Equations requiring arccos: structurally unsolvable with current operator set
- Total wall time: 34s

### ExprGenome comparison (abandoned)

Attempted smoke tier with ExprGenome at 300 generations. First equation took ~3.5 min/seed (vs ~1s for TreeGenome). By equation 2, method table growth pushed seed time to 7.3 min. Run abandoned after ~20 minutes with only 1.3 equations complete. ExprGenome did converge on 2/3 seeds for F=mu*Nn but the progressive slowdown makes it impractical without multiprocessing.

### Key decisions

- **TreeGenome only for this benchmark**: ExprGenome's `@eval` overhead and method table growth make it 100-200x slower in practice (not just the 10x from per-evaluation benchmarks).
- **Operator set**: Physics set (sin, cos, exp, abs) by default. Equations needing arcsin, arccos, tanh, or sqrt are structurally limited. Adding more operators would expand the search space.
- **Train/test split**: 200 train + 100 test, subsampled from PMLB's 100K rows. Deterministic shuffle with fixed seed.
- **Convergence criterion**: R² > 0.999 on held-out test set.
- **Not in CI**: This is a standalone example, not gated behind ARBORIST_RUN_BENCHMARKS.
