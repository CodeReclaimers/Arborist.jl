## Key decisions

- **Second benchmark: Koza-1** (not Santa Fe ant trail or XOR NEAT). Alan chose
  from Recommended. Ant trail would have constrained `threads=1` (not
  thread-safe); XOR NEAT has known distributed-innovation collisions. Koza-1 is
  robust and exercises the TreeGenome / GeneticProgramming path.
- **BP corpus strategy: freeze a `corpus_spec.toml`, not item bytes.**
  BinPackingEvaluator generates items in-process from `MersenneTwister(seed+ep)`;
  the per-seed stream is deterministic given the spec. Candidate seeds are drawn
  from the meta-seed at run time and not known ahead of registration, so
  freezing *all* item bytes is infeasible. Freezing the generator spec is the
  most faithful "bytewise-frozen" interpretation available; flagged in
  `bench/README.md`. Alternatives rejected: freezing bytes for baseline seeds
  only (inconsistent with candidate reps), flagging as harness-side contract
  mismatch (premature).
- **JULIA_NUM_THREADS baked into invocation template** (not caller env). The
  manifest's `threads = 8` declaration is the authoritative count; `--threads=8`
  in the invocation line makes the subprocess honor it regardless of who invokes
  `bench`. Alternative (rely on caller env) silently runs 1-threaded if anyone
  forgets to export.
- **1.0527 historical result import: deferred.** Establish a fresh baseline
  first at current SHA (per briefing §7 step 5); import 1.0527 later as
  `harness_version="pre-0.1.0"`.
- **Autoloop-harness wiring: separate pass.** Today's scope is contract plumbing
  and baseline, not autoloop redesign.
- **Corpus hash convention: sha256 of the single file in the corpus dir.**
  Each corpus dir currently has exactly one file. Documented in README; to be
  revisited if a corpus grows to multi-file.
- **Exercise-run interpretation:** the briefing's step 7 command
  (`bench run ... --seed-set baseline --foreground` on bin packing) would run
  the full 90-min baseline foreground, doubling cost. Using Koza-1 (~10 s) as
  the equivalent protocol shakedown — same plumbing path, different benchmark
  — saves ~90 min with no loss of coverage.

## What was intentionally NOT done

- **Did not modify the harness at `/home/alan/benchstone`.** Briefing explicitly
  out of scope. Noted one friction point (no `--repetitions N` flag on
  `bench run`, which makes a single-rep exercise run impossible) — reporting
  rather than patching.
- **Did not import the historical 1.0527 result.** Deferred per Alan's answer.
- **Did not wire the autoloop into `bench evaluate` / `bench promote`.** Deferred
  per Alan's answer (separate pass).
- **Did not run the 90-min baseline yet.** Pending commit + `bench register`;
  kicking off next.
- **Did not freeze per-seed item bytes for bin packing.** Explained above.
- **Did not add JSON.jl to `[deps]`.** Hand-rolled minimal JSON I/O in
  `bench/benchmarks.jl` instead; adding a runtime dep to Arborist for a
  benchmark wrapper would be scope creep against users who don't use bench.
- **Did not touch `examples/nsga2_tuning_config.jl`.** That is the editable
  surface for the autoloop; `bench/benchmarks.jl` wraps it without tuning.
